# Workout Plan

Workout Plan is a mobile app designed to help users create and manage personalized workout plans. The app allows users to build, edit, and execute workout routines with an intuitive and responsive interface, available in both English and Italian.

## Main Features:
- Create personalized workout plans.
- User profiling to suggest suitable exercises.
- Execute workouts with detailed control (pause, modify sets, summary).
- Dashboard with workout statistics.

## Technologies Used:
- **MVVM Architecture**
- **Kotlin Coroutines** for background thread management.
- **Room** for local database management.
- **Material Design** to enhance aesthetics and usability.
- **WorkManager** for background tasks.
- **RecyclerView** customized for displaying exercises and workouts.

   Open the project in Android Studio:

2. Open the project in Android Studio:

3. Configure Gradle:
   * Make sure to use Gradle JVM 11 or higher.
